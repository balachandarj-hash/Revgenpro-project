# Revgenpro-project

Landing apps for **RevGenPro Solutions Pvt Ltd** (Next.js 15 + Tailwind).

## Apps (kept separate)

| Folder | Cursor app | Offer |
|--------|------------|--------|
| `ai-videos/` | **ai-videos** | AI Videos landing (₹1,499) + `/product-advertisements` |
| `ai-product-videos-web/` | **new publish** (not `ai-videos`) | AI Promotional Product Videos ₹1,499 only at `/` |

## Development

```bash
# AI Videos landing
cd ai-videos && npm run dev -- --port 3458 --hostname 127.0.0.1

# Standalone product-video landing (Cursor publish)
cd ai-product-videos-web && npm run dev -- --port 3460 --hostname 127.0.0.1
```
