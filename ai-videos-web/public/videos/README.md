# Hero explainer (16:9)

| File | Purpose |
|------|---------|
| `hero-explainer-16x9.mp4` | Inline hero explainer (1920×1080, ~15s montage of creative demos) |
| `hero-explainer-poster.jpg` | Poster frame for the hero player |

To replace the explainer, drop a new **16:9** MP4 at `hero-explainer-16x9.mp4` and update `hero-explainer-poster.jpg`. Paths are wired in `src/lib/site-content.ts` → `hero.explainer`.

Portrait demos used in the portfolio carousel stay under `creative/`.
